Data Contracts

Draft YAML contracts for client-delivered monthly files.

These files are the version-controlled source of truth for layout matching, field mapping, and validation. A loader can parse them and mirror the contract body into Snowflake config.layout_contract, with individual field rows in config.layout_field_map.

Current drafts:

  • txn_velocity_standard.v1.yml mirrors the raw transaction file process in 01_Analysis/00-Scripts/analytics/txn_setup/04-define-data-func.py.
  • odd_extract.v1.yml mirrors the modified ODD-style account extract expected by the current Python pipeline.
  • intelligence_outputs.v1.yml documents the V1 engine output package and Snowflake targets.
