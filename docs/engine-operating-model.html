Operating Model

How people use the engine.

The CLI is the backend runner. The product experience belongs in the Velocity UI: readiness, run, review, export, consult, measure.

Engine map Engine build Data science plan Markdown source

User Workflow

No CLI for CSMs

1Stage filesClient sends ODD, TXN, extracts, workbooks.
2Select runCSM, month, client, product mode.
3Check readinessFiles, layout, match rate, history, confidence.
4Run enginePython engine runs behind the UI.
5Review storyAnalyst validates, consultant frames.
6Export packageBrief, action lists, data trust, measurement.

Who Sees What

CSM | analyst | consultant | client

CSMRun status, file readiness, warnings, client-ready downloads.
AnalystFeatures, PFI reasons, quality flags, model diagnostics.
ConsultantTop insights, financial impact, opportunity priority, proof.
ClientExecutive brief, target lists, campaign plays, measurement plan.
