Engine Flow

Files to action

1File ledgerPath, type, size, hash, lineage.
2Quality scoreCoverage, columns, match rate, warnings.
3Feature martAccount-month behavior and relationship signals.
4PFI verdictPrimary, split, competitor-primary, no verdict.
5OpportunitiesExpected value and priority score.
6InsightsStandard objects for decks, dashboards, APIs, Snowflake.

Opportunity Models

V1 scoring coverage

Debit activationNo/low-debit usage opportunity.

Competitor win-backExternal FI intensity and split relationship.
