Step Process

Do this before final Snowflake table design

1. Monthly File Drop

Client import files

Up to 15 files per month. Some match known layouts, some need mapping, some should be held out.

Known seed contracts

odd_extract.v1 and txn_velocity_standard.v1 exist, but they are not enough to describe every client.

2. Intake and Contract Mapping

Profile files

Detect delimiter, header, columns, row count, source family, period, and likely business role.

Map or flag gaps

Produce field mapping, missing required fields, join-key warnings, and data-team remediation.

3. Canonical Input Families

Account / ODD

Status, product, open/close dates, branch, age, business flag, debit flag, Reg E, balance.

Transactions

Account id, date, amount, type, merchant, MCC, channel, terminal, card present, transaction code.

Enrichment

Balance, product holdings, household/member, counterparty taxonomy, branch roster, suppressions.

Campaign and outcomes

Audience, wave, offer, response, holdout, activation, conversion, retained balance, churn.

4. Engine Products

Feature mart

Reusable account-month behavior and relationship features.

Verdicts and segments

PFI, external leakage, relationship depth, lifecycle, risk, readiness.

Action and measurement

Ranked opportunities, CSM queue, marketing export, banker list, baseline, outcomes.

Intelligence Products

What the analysis should produce
Data readiness

File ledger, layout gap report, account match rate, missing fields, confidence, blocker list.

Account-month feature mart

Activity, spend, payroll, external FI, balances, merchants, channel mix, relationship depth.

Counterparty graph

Merchant, payroll, competitor, lender, payment ecosystem, recurring relationship signals.

PFI and relationship verdicts

Primary with us, split, competitor-primary, no verdict, reason codes, confidence.

Opportunity portfolio

Payroll conversion, debit activation, deposit retention, competitor win-back, dormancy, expansion, attrition prevention.

Action package

CSM queue, analyst validation, marketing export, banker list, suppressions, measurement plan.

Insight registry

Standardized consulting findings with evidence, recommendation, owner, source sections, proof metric.

Outcome layer

Baseline, test/control assignment, outcome results, lift, persistence, month-over-month deltas.

Executive story

Situation, finding, implication, action, proof, top decisions, roadmap.

Known vs Unknown

The key design constraint

Known Now

  • Existing analysis inventory and script locations.
  • Major analysis domains and business questions.
  • Seed contracts for ODD-style account extracts and the raw transaction file.
  • Engine outputs such as feature mart, PFI, opportunities, insight registry, role exports, and measurement.

Unknown Until File Layouts

  • Exact monthly import files, table names, columns, delimiters, and header rules.
  • Which files are authoritative for account, transaction, balance, branch, campaign, suppression, and outcome data.
  • Join-key reliability and account-match coverage.
  • Which Snowflake tables should become durable facts, dimensions, marts, and views.
